# Rule Scope Index

## Scoped Routes

### JavaScript / Node Integration

- Applies to: files under `integration/**`, JS/TS source, `package.json`, or Node/npm tooling.
- Read:
  - `integration/AGENTS.md`

### Java CLI

- Applies to: files under `javascript-coverage-cli/**` or Java source/tests.
- Read:
  - `javascript-coverage-cli/AGENTS.md`

### Mixed Work

- Applies to: a concrete plan, changes or review involving both JavaScript / Node integration and Java CLI scopes.
- Read:
  - `integration/AGENTS.md`
  - `javascript-coverage-cli/AGENTS.md`

## Routing Rules

- When a more specific route exists under a broader routed directory, read both rule files and follow the more specific rule for that subtree.
- If initial fact-finding leaves two or more routes plausible and the task requires commands, a concrete plan, review, or code changes, read the `AGENTS.md` files listed by each plausible route.
